# Supabase connection

The frontend already sends quiz data to:

`POST /api/quiz`

The backend currently validates the data and logs it. To save it in Supabase, create a table such as:

```sql
create table public.customer_quiz_submissions (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  budget text not null,
  interests text not null,
  created_at timestamptz not null default now()
);
```

Then add your Supabase credentials to `.env`:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_SERVICE_ROLE_KEY=your_server_side_service_role_key
```

For a Node backend, install the official Supabase client:

```bash
npm install @supabase/supabase-js
```

Then replace the temporary section in `server.js` with a Supabase insert.

Important:
- Keep the service-role key ONLY on the backend.
- Never put the service-role key in `public/app.js`.
- The browser only needs to call `/api/quiz`.
- If you prefer Supabase's browser client with Row Level Security, use the anon key on the frontend and create an appropriate INSERT policy.

Example backend insert:

```js
const { createClient } = require("@supabase/supabase-js");

const supabase = createClient(
  process.env.SUPABASE_URL,
  process.env.SUPABASE_SERVICE_ROLE_KEY
);

const { data, error } = await supabase
  .from("customer_quiz_submissions")
  .insert([submission])
  .select()
  .single();
```
